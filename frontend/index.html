OpenList 多网盘备份与存储路径

解答：当 OpenList 绑定多个网盘时，备份文件究竟会存在哪个网盘？

OpenList 存储映射原理

OpenList 核心是将各个网盘映射为虚拟根目录下的文件夹：

├── /aliyun -> 对应你的「阿里云盘」

├── /onedrive -> 对应你的「OneDrive」

├── /quark -> 对应你的「夸克网盘」

└── /nas -> 对应你的「本地NAS」

💡 所以关键在路径前缀：如果设置备份路径为 /aliyun/QR-Relay-Backup，文件就会准确同步到阿里云盘；若设置为 /onedrive/中转站备份，就会同步到 OneDrive！

添加到手机主屏幕 获得原生 Web App 沉浸全屏体验

将 QR-Relay 保存到手机桌面后，可作为独立 Web App 打开，无浏览器顶部网址栏与底部工具条，全屏沉浸，启动更快！

iPhone / iPad (Safari 浏览器)
  1. 轻触屏幕底部中间的 分享图标（）；
  2. 向上滑动选项列表，点击 「添加到主屏幕」；
  3. 点击右上角 「添加」 即可在桌面生成 App 图标！
Android 安卓手机 (Chrome / 浏览器)
  1. 轻触浏览器右上角 更多菜单（）；
  2. 在菜单中点击 「安装应用」 或 「添加到主屏幕」；
  3. 确认添加即可在桌面生成图标。

💡 提示：若在微信中打开，请先点击右上角选择「在默认浏览器中打开」，再按上述步骤添加到主屏幕。
